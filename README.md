# Portfolio

Personal site for Roshan Agrawal, live at <https://roshan-agrawal4.github.io/portfolio/>.

Plain HTML, CSS and JavaScript. No framework, no build step, no dependencies. GitHub Pages serves
the files directly from `main`.

```
index.html        page content
css/styles.css    styling
js/stack.js       tech stack list
js/main.js        theme, navigation, animations
assets/           photo, résumé, logos, favicon
```

Run it locally with any static server:

```bash
python -m http.server 5173
```

Then open <http://localhost:5173>.
